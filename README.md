# Muhammad Hassaan Irshad — Portfolio Landing Page

## Files
- `index.html` — complete page structure/content
- `style.css` — responsive design system and layout
- `script.js` — mobile menu, active navigation and scroll progress
- `assets/portrait-main.jpg` — uploaded portrait
- `assets/portrait-secondary.jpg` — uploaded portrait

## Run
Open `index.html` directly in a browser, or use VS Code + Live Server.

## Before publishing
1. Replace `YOUR_EMAIL@example.com` in `index.html` with your real email.
2. Replace the LinkedIn/GitHub placeholder links with your real profiles.
3. Review dates and descriptions in the Experience section.
4. Add individual project links when your GitHub repositories are ready.

The page is fully responsive and uses Google Fonts (Inter + Poppins).
